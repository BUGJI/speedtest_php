# speedtest_php
在虚拟主机等环节测试网速，无需部署任何东西

# 使用

1. 将此文件(可重命名)放入你的虚拟主机目录
2. 访问你的虚拟主机域名，如果你改变了文件名字，请在你的域名后面加入你的文件名字
3. 点一下测速
